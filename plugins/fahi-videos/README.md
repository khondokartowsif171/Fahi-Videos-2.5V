# Fahi Videos 2.5V — Antigravity Plugin

[![mcptry](https://mcptry.com/badge/io.github.khondokartowsif171/fahi-videos-mcp)](https://mcptry.com/servers/io.github.khondokartowsif171/fahi-videos-mcp)

The official **Fahi Videos 2.5V** plugin for Antigravity, providing AI agents with 10 free-first video production tools, Bangladeshi Bengali voiceover dubbing, social video downloading, and CapCut NLE video editing blueprints.

## ✨ Capabilities

- **🎙️ Kotha Studio Bangla TTS**: Generate natural Bengali speech (WAV/MP3 base64) using 4 custom personas (`Kore`, `Puck`, `Charon`, `Zephyr`).
- **📥 Universal Downloader**: Extract downloadable MP4/MP3 streams from YouTube, Facebook, Instagram Reels, and TikTok.
- **✂️ CapCut Pro Blueprint Engine**: Compute timeline splits, SMPTE `00:00:00:00` timecodes, keyframe easing curves, CSS mask clip-paths, and animations.
- **📢 E-Commerce UGC Storyboards**: Multi-scene marketing ad builder with scripts, Banglish director cues, and SRT subtitles.
- **🔊 Pure Studio SFX**: Synthesize 16-bit 44.1kHz WAV sound effects (whoosh, pop, click, riser).
